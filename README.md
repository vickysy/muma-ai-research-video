# 木妈 AI 新品研究视频

把“这个 AI 为什么火，我到底要不要用”做成普通人看得懂的研究视频。

这套 Skill 来自木妈对 Jev 的真实探索：研究创始人、安装试用、寻找公开案例、反复改稿，最后制作成约三分钟的视频。它保留的是这次探索中有效的工作方法，而不是要求每个产品都套用 Jev 的结论。

**一条主线：创始人的问题 → 真实案例 → 我的体验 → 谁需要用。**

## 能交付什么

- 约 3–4 分钟、有真实操作画面的中文研究视频，默认 H.264/AAC MP4。
- 定稿口播、SRT 字幕、素材来源及声画时间线。
- 参考研究对象官网风格的 **3:4 竖版 + 4:3 横版封面**。
- 可复制的视频号标题/摘要、小红书标题/正文/话题。
- 视频、字幕时间和封面比例的技术验收记录。

它是供 AI 助手执行的工作流程与检查脚本，**不是独立剪辑软件**。制作仍需要联网检索、媒体处理、配音、图像生成与视频渲染工具；相关服务的账号、费用和使用权限由使用者自行配置。

## 这样使用

完整作品：

> 用 $muma-ai-research-video 研究【产品名称或官方链接】为什么火。先看创始人要解决的问题，再找多个真实演示。结合我给你的试用感受，做约三分钟视频、官网风格的横竖封面，以及视频号和小红书发布文案。

只有研究线索，还没试过：

> 用这个 Skill 整理创始人一手资料和公开案例，明确哪些是作者演示、哪些还没有验证。先不要写成“我已经实测”。

只改封面：

> 按这个 Skill，把两张封面改成我发的官网截图风格，文案不变，视频不用重做。

## 工作方式

1. 明确真实疑问、受众、本人体验和本次交付范围。
2. 从创始人访谈、官方文档与发布资料追到产品动机。
3. 广搜案例，再选有可靠来源、用途不同、能展示结果的素材。
4. 写独立口播稿，文章和视频分别组织。
5. 将真实操作、结果画面与最终旁白对齐，再剪辑和配字幕。
6. 按产品当前官网或用户指定风格分别做横竖封面。
7. 校对事实、画面、声音和文件，交付 MP4 与发布配套。

默认节奏以 **1.3 倍保调旁白**为起点；无配乐、无固定品牌关注号召。所有默认值都可由本次要求覆盖。作者的公开演示不等于独立复现，不虚构个人试用经历，也不保证使用效果或传播数据。

## 配音与工具

- 使用当前使用者有权使用的旁白音色。此仓库**不包含木妈的声音文件、克隆音色权限或任何 API 密钥**。
- 视频工程可以使用 HyperFrames 或当前可用的其他剪辑工具；使用 HyperFrames 时按其当前 Skill/文档操作。
- 图像封面默认使用所在环境可用的图像生成工具。
- 技术验收需要 Python 3、FFmpeg 和 ffprobe；脚本本身不需要第三方 Python 包。
- 命名为 imagegen、hyperframes 等的配套 Skill 并未打包在本仓库内。缺少能力时先说明缺口，不把未生成的产物写成完成。

## 技术验收

在本仓库目录运行：

```bash
python3 scripts/verify_delivery.py \
  --video /path/to/video.mp4 \
  --srt /path/to/video.srt \
  --portrait /path/to/cover-3x4.jpg \
  --landscape /path/to/cover-4x3.jpg \
  --full-decode \
  --report /path/to/verification.json
```

只检查部分交付时可以省略字幕或封面参数。省略 --full-decode 就不会解码全片。脚本不能替代事实审查、画面阅读或音色试听。
